# Bengisu Koc — Astrophysics Portfolio

A lightweight first draft of Bengisu's portfolio site. It is deliberately content-ready: the field-notes and writing sections are placeholders for future lab work, projects and blog posts.

## Edit points

- `index.html` contains all copy, navigation and project placeholders.
- `styles.css` contains the visual system (soft pink, paper white, dusty lavender) and responsive layout.
- `script.js` handles the subtle reveal transitions.
